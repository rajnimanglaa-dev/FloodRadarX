# AI/ML Data

## flood_readings.csv
This is simulated sample data created only for testing the data processor.

It is NOT real river or rainfall data and must NOT be used as verified flood-history data.

## processed_flood_data.csv
Generated by flood_data_processor.py from the simulated sample data.
